# เว็บไซต์ บ้านสร้างคัพ ครั้งที่ 1

เว็บไซต์สำหรับจัดการแข่งขันฟุตซอล ธีมกระดานคะแนนสนามยามค่ำคืน (โทนกรมท่า/น้ำเงิน-แดง-ทอง
ให้เข้ากับโปสเตอร์) โฮสต์ฟรีบน **GitHub Pages** และแก้ไขข้อมูลทั้งหมดผ่าน **Google Sheet**
โดยไม่ต้องแตะโค้ดอีกเลยหลังตั้งค่าครั้งแรก

## โครงสร้างไฟล์

```
futsal-site/
├── index.html          หน้าแรก (เบนเนอร์, ผลล่าสุด, โปรแกรม, ตารางคะแนน, ข่าว)
├── schedule.html        ตารางการแข่งขันทั้งหมด + ตัวกรอง
├── draw.html             ผลจับฉลากแบ่งสาย + ตารางคะแนนแยกสาย
├── rules.html            กฎกติกา ค่าสมัคร เงินรางวัล
├── news.html             ข่าวสารทั้งหมด
├── README.md
└── assets/
    ├── css/style.css
    └── js/
        ├── config.js     ตั้งค่า SHEET_ID + ข้อมูลตัวอย่าง (สำรอง)
        ├── sheets.js      ตัวดึงข้อมูลจาก Google Sheet
        └── app.js         ฟังก์ชันแสดงผลที่ใช้ร่วมกันทุกหน้า
```

## ขั้นตอนตั้งค่า (ทำครั้งเดียว)

### 1) สร้าง Google Sheet

สร้างสเปรดชีตใหม่ 1 ไฟล์ แล้วสร้างแท็บ (sheet tab) 4 แท็บ ชื่อตรงตามนี้:
`Settings`, `Teams`, `Matches`, `News`

**แท็บ `Settings`** — คีย์/ค่า ใช้คุมข้อความ+รูปเบนเนอร์ทั้งเว็บ (แถวแรกเป็นหัวคอลัมน์ `key`, `value`)

| key | value |
|---|---|
| site_title | บ้านสร้างคัพ ครั้งที่ 1 |
| site_subtitle | การแข่งขันฟุตซอลการกุศลโอเพ่น |
| banner_tagline | รายได้ทั้งหมด... |
| banner_image_url | (ลิงก์รูปเบนเนอร์ — อัปโหลดรูปที่ Imgur/Google Drive แบบแชร์สาธารณะแล้ววางลิงก์ตรงนี้) |
| event_dates | 6–8 พฤศจิกายน 2569 |
| venue_name | สนามฟุตซอลชายน้ำบ้านสร้าง (ไม่มีโดม) |
| venue_address | อ.บ้านสร้าง จ.ปราจีนบุรี |
| half_minutes | 15 |
| contact1_name / contact1_phone | คุณโชค / 098-665-3916 |
| contact2_name / contact2_phone | คุณเบญ / 065-636-2988 |
| teams_u12, fee_u12, deposit_u12, prize_u12_1..3, age_u12 | ตามรุ่นไม่เกิน 12 ปี |
| teams_u14, fee_u14, deposit_u14, prize_u14_1..3, age_u14 | ตามรุ่นไม่เกิน 14 ปี |

> **เปลี่ยนรูปเบนเนอร์เมื่อไหร่ก็ได้** เพียงแก้ค่า `banner_image_url` ในชีต ไม่ต้องแก้โค้ด

**แท็บ `Teams`** — หัวคอลัมน์: `id, division, group, name`
`division` ใส่ `U12` หรือ `U14`, `group` ใส่ตัวอักษรสาย เช่น `A`, `B`, `C`

**แท็บ `Matches`** — หัวคอลัมน์:
`id, division, group, round, date, time, venue, team_home, team_away, score_home, score_away, status`
- `date` รูปแบบ `2569-11-06` (ปี-เดือน-วัน)
- `status` ใส่ `upcoming` / `live` / `finished`
- คู่ที่ยังไม่แข่ง ปล่อย `score_home`, `score_away` ว่างไว้

**แท็บ `News`** — หัวคอลัมน์: `id, date, title, excerpt, content, image_url`

### 2) เผยแพร่ชีตสู่เว็บ

ใน Google Sheet: **File → Share → Publish to web** → เลือก "Entire Document" →
กด Publish (ทำครั้งเดียว ไม่ต้องทำซ้ำทุกครั้งที่แก้ข้อมูล)

จากนั้นตรวจสิทธิ์การแชร์: กดปุ่ม **Share** มุมขวาบน → เปลี่ยนเป็น
**"Anyone with the link" = Viewer** (เว็บไซต์อ่านข้อมูลได้แบบสาธารณะ แต่แก้ไขไม่ได้)

### 3) เอา Sheet ID มาใส่ในโค้ด

คัดลอกรหัสจาก URL ของชีต:
```
https://docs.google.com/spreadsheets/d/1AbCxxxxxxxxxxxxxxxxxxxxxxxxxxxx/edit
                                       ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^ อันนี้
```
เปิดไฟล์ `assets/js/config.js` แล้วแก้บรรทัด:
```js
const SHEET_ID = "1AbCxxxxxxxxxxxxxxxxxxxxxxxxxxxx";
```

### 4) อัปโหลดขึ้น GitHub แล้วเปิด GitHub Pages

1. สร้าง repository ใหม่ (public) บน GitHub เช่น `bansang-cup`
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (ลาก-วางผ่านหน้าเว็บ GitHub ได้เลย หรือใช้ `git push`)
3. ไปที่ **Settings → Pages** ของ repo → Source เลือก branch `main` โฟลเดอร์ `/ (root)` → Save
4. รอ 1–2 นาที จะได้ลิงก์เว็บไซต์รูปแบบ `https://<ชื่อผู้ใช้>.github.io/bansang-cup/`

หลังจากนี้ **การอัปเดตข้อมูลประจำวัน (ผลบอล ตารางแข่ง ข่าว) ทำในหน้า Google Sheet ได้เลย
ไม่ต้องแตะ GitHub อีก** — เว็บไซต์จะดึงข้อมูลใหม่ทุกครั้งที่มีคนเข้าเว็บ

## แนวทางหน้าตาแบบ "ลีกอาชีพ" ที่ใส่ไว้ให้แล้ว

สิ่งที่เว็บลีกกีฬามาตรฐาน (เช่น เว็บพรีเมียร์ลีก, ไทยลีก) มักมี และผมออกแบบไว้ในเว็บนี้แล้ว:

- **เมนูหลักครบ 5 จุด**: หน้าแรก / ตารางแข่งขัน / จับฉลากแบ่งสาย / กฎกติกา / ข่าวสาร
- **แถบผลสด/โปรแกรมแบบ ticker** ไล่เลื่อนใต้เบนเนอร์ (สไตล์กระดานคะแนนถ่ายทอดสด)
- **หน้าแรกสรุปทุกอย่างในหน้าเดียว**: ผล 3 นัดล่าสุด, โปรแกวมที่จะแข่ง 3 นัด, ตารางคะแนนสายแรกของแต่ละรุ่น, ข่าว 3 ข่าวล่าสุด
- **ตารางคะแนนคำนวณอัตโนมัติ** จากผลแมตช์ที่กรอกในชีต (แข่ง/ชนะ/เสมอ/แพ้/ได้-เสีย/คะแนน) ไม่ต้องกรอกอันดับเอง
- **ตัวกรองตารางแข่งขัน** ตามรุ่นอายุ / สาย / สถานะ (สไตล์เว็บลีกใหญ่ที่กรองตามสโมสร/สัปดาห์)
- **แบ่งสีตามรุ่นอายุชัดเจน** น้ำเงิน = รุ่น 12 ปี, แดง = รุ่น 14 ปี ให้แยกแยะง่ายทั้งเว็บ
- **รองรับมือถือเต็มรูปแบบ** เมนูพับเป็นแฮมเบอร์เกอร์ ตารางเลื่อนดูได้

### แนะนำเพิ่มเติมถ้าต้องการยกระดับอีกขั้น (ยังไม่ได้ทำในเวอร์ชันนี้)
- หน้าโปรไฟล์ทีม/นักเตะแยกรายทีม พร้อมสถิติผู้ทำประตูสูงสุด
- ระบบแจ้งเตือนผ่าน Line OA เมื่อมีการอัปเดตผลบอล
- แกลเลอรีภาพ/วิดีโอไฮไลต์หลังจบแต่ละวันแข่งขัน
- ฟอร์มสมัครทีมออนไลน์ (เชื่อมกับ Google Form ไปเก็บใน Sheet เดียวกันได้)

## หมายเหตุเรื่องความปลอดภัยของข้อมูล

การตั้งค่า "Publish to web" ทำให้ **ใครก็ตามที่มีลิงก์อ่านข้อมูลในชีตได้** (แต่แก้ไขไม่ได้ เพราะ
เป็นการอ่านอย่างเดียวผ่าน gviz API) หากมีข้อมูลที่ไม่ต้องการเปิดเผย เช่น เบอร์โทรส่วนตัวของ
ผู้เล่น ไม่ควรใส่ในชีตนี้ — ใส่เฉพาะข้อมูลที่ตั้งใจแสดงต่อสาธารณะบนเว็บไซต์เท่านั้น
